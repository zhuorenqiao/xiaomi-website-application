# Git 提交信息规则

本工作区包含两个独立 Git 仓库：`front/`（React 前端，Vite）与 `back/`（Spring Boot 后端，Maven 多模块），两个仓库统一使用以下提交信息风格。

## 格式

```
<type>: <中文描述>
```

## 规则

- `type` 使用英文小写，常用值：
  - `feat`：新功能
  - `fix`：缺陷修复
  - `refactor`：重构（不改外部行为）
  - `build`：构建、依赖、容器化、部署配置
  - `docs`：文档
  - `chore`：其他杂项
- 描述用中文，简明扼要，结尾不加句号；必要时用括号补充范围或说明
- 一次提交只做一件事，不混合无关改动
- 示例（来自本工作区现有提交）：
  - `feat: 新增小米在线客服聊天功能`
  - `feat: 从前端仓库迁出并重构为 Maven 多模块工程（chat-api + chat-service）`
  - `build: 添加 Docker 配置文件用于项目容器化部署`
